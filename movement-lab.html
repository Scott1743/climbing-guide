髋的位置点选图中的关节

橙色圆环帮助你追踪屁股去了哪里。它不是全身重心的精确测量。

带着一个问题看

怎么读：双环表示目标，绿色圈表示踩点，橙色圈表示勾住；虚线是路径。动画下方实时显示接触状态与图示肘角。准备和稳定时展开支撑臂，发力与转换时允许屈臂；直臂不等于锁死肘或完全放松肩。正身与侧身配俯视图，挂脚配接触放大图；dyno 会明确展示四点离壁与双手接点。

13 个攀岩场景：什么时候用，怎样接起来

先读场景条件，再点名称观看动画。左右方向只是一个条件，还要结合脚点、身体位置和下一次出手。

向右上够点

目标在右上，右边也有一个更合适的脚点。先换脚的位置，再把髋移过去，最后出右手。

看好点位 → 踩脚准备 → 移动髋部 → 蹬腿伸手

向左上够点

这组点位与第一个场景左右对称。先放好左脚，再把髋移向左边，最后出左手。

看好点位 → 踩脚准备 → 移动髋部 → 蹬腿伸手

手点有点高

目标主要在上方。先找到较高的脚点，再把身体移到能推起的位置；站起时，另一只脚可以离开低脚点。

看好点位 → 踩脚准备 → 移动髋部 → 蹬腿伸手

外旗

右脚有可用支撑，左脚没有合适的新点。左腿向左侧伸出，配合髋的位置调整，再尝试移动右手。

看好点位 → 踩脚准备 → 移动髋部 → 蹬腿伸手

换脚

中间是一个足够大的脚点。先把左脚换过去接替支撑，腾出右脚去踩右侧点，然后再移动身体。

看好点位 → 踩脚准备 → 移动髋部 → 蹬腿伸手

正身蹬起

两侧都有合适的脚点，目标主要在上方。胸与髋大致正对墙，先站起，再移动右手；不必每一步都强行转髋。

看点位 → 踩稳两脚 → 正身站起 → 右手接点

侧身转髋

脚点允许身体转动时，可以让一侧髋靠近墙，改变肩的位置和出手方向。主体是沿墙投影，转动请同时看左上俯视图。

起步 → 右脚找位 → 转右髋 → 右手出手

背旗

左手与左脚保留连接，右手准备向右出。右腿从左腿后方穿过，帮助把身体安排到支撑附近；和外旗的走向不同。

辨认支撑 → 右腿后穿 → 髋找位置 → 右手出手

脚跟勾

左侧凸点提供脚跟接触面。抬起左脚，脚跟放到点上并主动拉住，让髋靠近左侧，再出左手；它不是普通的脚尖踩点。

找可勾的点 → 放好脚跟 → 主动勾拉 → 左手出手

脚尖勾

在有合适下缘的点或体积上，用脚背靠近脚尖的胶面勾住。左脚形成拉的连接，配合右脚踩点，让右手有机会移动。

看下缘 → 放入脚尖 → 保持勾拉 → 右手接点

并手

右边的大手点有足够位置容纳两手。左手跟到右手所在点，再让右手继续往右出；并手是在重新分配下一次出手。

读点位 → 安排脚 → 身体靠近 → 左手并入 → 右手再出

Dyno 动态跳

双手 dyno 的手臂姿态会改变：下沉准备时展开，蹬起时屈曲配合，远点接点时伸长，再经过屈臂缓冲回到长臂。肩始终保持主动控制。

预备 → 展开手臂 → 蹬起 → 腾空 → 长臂接点 → 屈臂缓冲 → 恢复长臂

连续动作串联

同一组连续点位：先换脚让右脚去右侧，再用外旗辅助左手并到大点，最后继续出右手。每个技巧都在为下一次移动服务。

读线 → 换脚 → 右脚踩点 → 外旗 → 移髋 → 并手 → 再出手

图里的几个词，分别在解决什么？

正身：胸与髋大致正对墙，两腿可以参与推起。侧身：一侧髋转向墙，改变肩与目标的位置。旗式：自由腿调整身体分布，帮助处理失衡；它不一定要踩点。脚跟勾 / 脚尖勾：用脚跟或脚背前端与岩点形成拉的连接，和普通脚尖踩点不同。并手：两手先后占据同一大手点，重新安排下一只出手。换脚：一只脚接替另一只脚的位置。Dyno：借助蹬起和身体动量完成远距转移，本页展示四点离壁的一种。

动作说明参考：REI 动作基础 · 脚跟勾教学 · 脚尖勾教学。动画为原创简化示意。

动作是条件明确的教学示例，不能按左右方向硬套。主体采用二维关节模型，俯视与挂脚补图展示额外关系；不计算摩擦、抓握或关节负荷，髋标记不是精确重心。动态场景经过分解慢放，不代表真实的飞行速度、重力轨迹或抓点时机。
